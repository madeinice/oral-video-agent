# 分镜、时间与质量

## 给用户的交流格式

生成前按 [审核单模板](../assets/review-template.md) 在对话中完整展示：**口播位置 / 画面安排 / 动效 / 音效 / 是否需要人物**。触发词、动作与进退场写进动效列，素材内容与来源写进画面安排列；不要另换列名或遗漏音效列。随后列出实际人物与声音参考、语速、画幅和画质，等待用户确认本版。用户不需要描述 easing、坐标、遮罩格式。把“讲到记录时画一条线”转换为对应词的实际音频时间。

1. 音频确定之前用词语锚点，秒数只能标为估计。
2. 配音锁定后保存词级时间戳，格式为 `[{"text":"记录","start":1.2,"end":1.6}]`，单位秒。
3. `project.py anchor --words words.json --phrase 记录` 返回边界；重复词需 `--occurrence 2`。ASR 错字先听音校正，不用模糊匹配悄悄放错位置。
4. 精度不超过原始时间戳的粒度；整句一个 token 不能称为字级对齐。语音首尾静音保留时，同样保留在时间轴中。
5. 通篇改变速度后，所有字幕、动效、音效、素材切点同步换算。避免只改视频帧率造成口型或声音漂移。

## 常用动效

| 意图 | 动作与时长起点 | 注意 |
| --- | --- | --- |
| 提到两个人 | 圆头像分别从左右进入，0.25–0.4 秒缓出，句末退出 | 头像出现分别锚定姓名，暖色细边框；不要遮脸 |
| 解释流程 | 竖线先画出，每个节点在对应词处进入 | 记录→数据化→分析；节点需要各自的时间，不平均分配 |
| 人物让位 | 将人物平滑缩入下角，主信息进入空出区域 | 留安全边距，不把人物硬切成太小方块；真实转场可扩展模板 |
| 关键词 | 大字轻推/淡入，读完收走 | 一屏一个主强调，不常驻标签 |
| 人物身后大字 | 原视频底层→文字→逐帧人物前景 | 需要与视频帧和裁切一致的透明前景；检查头发、肩膀、遮挡 |
| 全屏 B-roll | 保留人声，素材自身静音 | 对应语义，色温、明暗与画面运动保持一致 |

模板的图层按 JSON 数组顺序从底到顶，再绘制字幕。`foreground` 应放在身后文字之后、字幕之前。透明 WebM 或有透明通道的可用视频需要验证 Chromium 解码；不要用一张静止人物抠图覆盖整段活动人物冒充遮罩。

## 人声与音效

先锁定人声，再加音效。SFX 初始可设约 -22 dB（线性音量约 0.08），逐个试听，这不是保证绝对响度的数值。原素材很响时进一步降低或处理。检查真实峰值与整体响度，语音始终清晰。默认无 BGM，不从 B-roll 偷带音乐。

中文配音速度 = 汉字数 / 实际发声秒数；用 VAD 或复听确定发声区间，不拿文件总时长当发声时长。对长文案不要仅靠压缩到固定时长实现快语速；过度变速会损害自然度。

## 素材与来源

使用 [来源表模板](../assets/examples/sources.example.json)。记录下载的具体页面、许可页、作者、日期和使用片段。用户要求“去网上找”允许检索与按许可下载，不代表可以移除水印或绕过下载限制。缺合适素材时可用简单图解或告知缺口，别用不相干镜头凑数。

## 最终验收

- 听全片：无漏句、吞字、双人声、尖锐音效、未请求音乐。
- 检查首帧、每个转场、B-roll 返回人物、最后一帧：无黑屏、冻帧、突兀裁切。
- 看字幕、人名、英文：语义与声音一致；没有把所有字均分在时长中。
- 逐项检查锚点与脸部遮挡；竖屏文字不挤到边缘。
- ffprobe 记录宽高、帧率、时长和音轨；FFmpeg 全片解码一次排查损坏。
- 记录原生人物分辨率、是否超分、最终导出分辨率；不把导出尺寸当原生质量。
- 交付目录包含 MP4、SRT、工程、sources.json、实际流程与剩余限制说明。

只扩大验证来解决明确风险；不用重复整片收费生成来修复本地动效。
